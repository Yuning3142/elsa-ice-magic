# Elsa Ice Magic — Mac 手势冰雪魔法

## 要求
- macOS、摄像头、Chrome 或 Safari（推荐最新版 Chrome）
- Node.js 20.19+ 或 22.12+（推荐 Node.js 22 LTS）
- 首次加载 MediaPipe 模型需要互联网

## 启动
在终端进入本项目目录：

```bash
npm install
npm run dev
```

打开终端显示的地址，通常为 `http://127.0.0.1:5173`。
点击「开启冰雪魔法」，允许浏览器访问摄像头。无需 Python、无需 API key。

## 手势
- 张开手掌：雪花粒子
- 伸出食指、其他手指收起：指尖冰霜轨迹
- 握拳：能量汇聚
- 握拳后快速张开：冰晶爆炸（需要同一只手连续被追踪）
- 两只手张开且相隔较远：从天而降的暴风雪
- 双手快速上抬：冰刺从地面升起
- OK 手势（拇指食指相触、其余三指伸直）保持 0.4 秒：雪花法阵
- 伸出食指快速一甩：冰锥飞弹
- 双手从两侧快速合拢：冰环冲击波
- 双手握拳保持 1 秒：冰封画面（张开手掌解冻）
- 比 ✌ 剪刀手保持 0.5 秒：这只手覆上冰甲（戴甲甩食指射出三连冰锥），再比一次 ✌ 解除

`H` 隐藏/显示界面；`F` 全屏。

## 注意
- 模型基于启发式手指伸展检测，不保证复杂手势 100% 识别；光照均匀、手掌面向镜头更稳定。
- 画面采用镜像，与照镜子一致。
- 视频只在本机浏览器中处理；浏览器会从 Google/CDN 下载模型与运行库。
- 若 macOS 未弹出授权：系统设置 → 隐私与安全性 → 摄像头，允许浏览器使用。
- 如果首次加载失败，检查网络能否访问 jsDelivr 和 Google Storage。

## 代码结构
- `index.html`：摄像头、UI
- `src/main.js`：MediaPipe 初始化、手势状态机、双手逻辑
- `src/effects.js`：Three.js 粒子系统、发光雪花纹理
- `src/style.css`：界面风格
