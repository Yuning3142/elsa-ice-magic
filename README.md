# ❄ Elsa Ice Magic — 手势冰雪魔法

对着摄像头挥挥手，就能像冰雪女王一样施展冰雪魔法。支持 **Windows** 和 **Mac**，在浏览器里直接运行，无需安装。

## 👉 在线体验

**https://yuning3142.github.io/elsa-ice-magic/**

1. 用 **Chrome** 或 **Edge** 打开上面的链接
2. 点击「开启冰雪魔法」
3. 浏览器询问时，允许使用摄像头

第一次打开需要下载手势识别模型，可能要等几秒。

## 手势

| 手势 | 魔法 |
| --- | --- |
| ✋ 张开手掌 | 雪花飘落 |
| ☝ 伸出食指 | 指尖冰霜轨迹 |
| ☝ 伸出食指快速一甩 | 冰锥飞弹 |
| ✊ 握拳 | 能量汇聚 |
| ✊ → ✋ 握拳后快速张开 | 冰晶爆炸 |
| 👌 OK 手势保持 0.4 秒 | 雪花法阵 |
| ✌ 剪刀手保持 0.5 秒 | 这只手覆上冰手套，戴着冰手套甩食指会射出三连冰锥；再比一次 ✌ 解除 |
| 🙌 双手张开、左右分开 | 从天而降的暴风雪 |
| ⬆ 双手一起快速上抬 | 冰刺从地面升起 |
| 👏 双手从两侧快速合拢 | 冰环冲击波 |
| ✊✊ 双手握拳保持 1 秒 | 冰封画面（张开手掌解冻） |

键盘：`H` 隐藏/显示界面，`F` 全屏。

**识别小贴士：** 光线均匀、手掌正对镜头、双手完整出现在画面里时识别最稳定。画面是镜像的，和照镜子一样。

## 摄像头打不开？

页面右上角会显示具体原因。常见的解决方法：

**浏览器：** 点地址栏左侧的图标，把「摄像头」设为允许，然后刷新页面。

**Windows 10 / 11**
- 设置 → 隐私和安全性 → 摄像头：打开「摄像头访问」「让应用访问你的摄像头」和「让桌面应用访问你的摄像头」
- Windows 上摄像头同一时间只能被一个程序使用，请先关掉 Teams、Zoom、微信视频、相机等程序
- 部分笔记本有摄像头物理开关或 Fn 快捷键（键帽上带摄像头图标），确认已经打开

**Mac：** 系统设置 → 隐私与安全性 → 摄像头，打开浏览器的开关，然后重启浏览器。

**模型加载失败：** 检查网络能否访问 `storage.googleapis.com`，模型从这里下载。

## 隐私

摄像头画面只在你自己的浏览器里处理，不会上传到任何服务器。

## 本地运行

需要 [Node.js](https://nodejs.org/) 20.19+ 或 22.12+（推荐 22 LTS）。Mac 用「终端」，Windows 用「PowerShell」或「命令提示符」，进入项目目录后运行：

```bash
npm install
npm run dev
```

然后在浏览器打开终端里显示的地址（通常是 `http://127.0.0.1:5173`）。不需要 Python，也不需要 API key。

## 技术实现

- **手势识别：** Google [MediaPipe](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker) HandLandmarker 识别每只手的 21 个关键点，再由 `classify()` 根据手指伸展情况和前后帧的运动判断手势
- **特效：** [Three.js](https://threejs.org/) 负责粒子、冰刺、法阵和冰环；冰手套和冰封画面用 Canvas 2D 绘制
- **部署：** 推送到 `main` 后，GitHub Actions 自动构建并发布到 GitHub Pages

| 文件 | 内容 |
| --- | --- |
| `index.html` | 页面结构、手势说明面板 |
| `src/main.js` | MediaPipe 初始化、手势判断、双手动作 |
| `src/effects.js` | 所有冰雪特效 |
| `src/style.css` | 界面样式 |
| `.github/workflows/pages.yml` | GitHub Pages 自动部署 |
